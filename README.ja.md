# SAISENT 4.0

このマシンで今起動しているエージェントセッションへ、あらかじめ用意したテキストを貼り付ける操作パネル。

正しいセッションのキューにテキストを入れると、SAISENT がエージェントのウィンドウをアクティブにし、
そのセッションのタブへ切り替え、テキストを一度の操作で貼り付けて Enter を押します。

## クイックスタート

```
START_SAISENT.bat
```

Windows で Python 3.11+ が必要です。

## 使い方

1. **エージェント。** 上の行 — チェックボックス: Claude Code、Freebuff、Antigravity、CodeNomad。
   チェックしたエージェントのセッションが左のパネルに表示されます。
2. **ライブセッション。** 左パネルは実際に動いているもの: セッション名、タブ番号、アクティビティセンサー、プロジェクト。
   リストは「毎 N 秒」を有効にしない限り自動更新されません — 既定では **更新** ボタンでのみ更新します。
3. **タブ。** SAISENT はセッションの起動順からタブ番号を推測します。間違っている場合は
   `SAISENT.json` の `tabs` キーでセッションごとに上書きします(例 `{ "tabs": { "claude-code:abc123": 3 } }`、
   キーは `<agent>:<id>` 形式)。`0` = タブを切り替えない。
4. **テキスト。** 右下のボックスに書く(または貼り付ける)、**キュー** (または Ctrl+Enter) を押す。
   **全キュー** は同じテキストをすべてのライブセッションに入れる — 旧「CTRL+2、テキスト、CTRL+3、テキスト」マクロの置き換え。
5. **キュー。** 行順 = 送信順。マウスでドラッグするか **上**/**下** ボタンで移動。セッションごとに独自のキュー。
   行をダブルクリック(または **編集**)でプロンプトをテキストボックスに戻す; **編集を保存** はその場で上書き、
   **キャンセル** は破棄。送信済みプロンプトの編集はキューに戻す — 行内のテキストはもはやセッションが受けたものではない。
   **複製** は直下にコピーを置く。
6. **送信。** **このキューを送信** — 選択セッションのみ。**すべてのキューを送信** — 順番にすべて。
   **ドライラン** は何も送らず、ログに計画だけを表示。実際の送信は確認を求め、セッション名を挙げる。

## 送信の取り消し

送信後、**取り消し** ボタンが30秒間表示されます。最後に送信したプロンプトをキューに pending として戻す —
セッションがすでに処理済み(確認済み配信)の場合を除く。

## スケジュールと制限

「送信」グループ内:

- **送信時刻 (HH:MM)** — 空 = 「今すぐ」。時刻があると、キューはその時刻の次回発生まで待つ
  (今日、過ぎていれば明日) そしてステータスバーにカウントダウンを表示。
- **レート制限のリセットを待つ** — 各プロンプトの前に SAISENT はエージェント自身のテキストを読む。
  「limit reached」ならキューは待ち、制限が解けると自動で再開。ロックされたドアにはプロンプトを打たない。
- **制限を確認** — 今すぐ再スキャン。
- 右のステータスフィールドはライブ状態: `limits: all agents free` または
  `claude-code: LIMITED until 09:22 (1h 05m remaining)`(赤)。カウントダウンはキャッシュから毎秒刻む;
  ディスクは読み取りが古くなったか、指定されたリセット時刻が来たときだけ触れる。

リセット時刻はエージェント自身の言葉から取る。エージェントが明言しない場合、SAISENT は
「reset time not stated」と書き、+5時間のようなプレースホルダーを捏造しない。

### 制限がリセットされる時期

エージェントがリセット時刻を一度も明言しない場合、SAISENT はエージェントごとの規則にフォールバック:

| エージェント | 規則 | 意味 |
|---|---|---|
| Freebuff | `daily 10:00` | 毎日 10:00 にリセット |
| CodeNomad | `daily 03:00` | 毎日 03:00 にリセット |
| Claude Code | `rolling 5h` | 最後に送信したプロンプトから 5 時間後 |
| Antigravity | エージェントの言葉のみ | 規則なし — 明言したもの、または何もない |

規則はエージェントが明言した時刻を決して上書きしない; エージェントが自分のクォータの権威。
`SAISENT.json` の `quota_plans` で任意の規則を上書きできる(例 `{ "quota_plans": { "claude-code": "rolling 3h" } }`)。

## 次のものが送信されない理由

送信は厳密に順次で、最初の本当のエラーで停止します。理由はステータスバー
(`stopped: window not found: ...`)、リストのプロンプト行、ログに現れます。残りは `pending` のまま —
失われません。

プロンプト間には `gap_ms` の一時停止(既定 1500 ms)があり、ステータスは `Waiting N.Ns before next` を表示。
プロンプトが送信されたがセッションが動かない場合、**未確認** とマークされキューに残る。「送信済み」は
確認済み配信にのみ適用される。

## アクティビティセンサー

「センサー」列は「今すぐ入力できるか」に答える。

- `busy` — セッションが 20 秒未満前にストアに書き込んだ(エージェントが手番の途中);
- `idle` — 20 秒超の沈黙、入力フィールドは空き。

由来:

| エージェント | ソース | センサー |
|---|---|---|
| Claude Code | `~/.claude/sessions/<pid>.json` + トランスクリプト | トランスクリプトの最終書き込み時刻 |
| Freebuff | `<project>/.freebuff/desktop-v2.db`、`threads` テーブル | `turn_state` フィールド |
| Antigravity | `~/.gemini/antigravity/conversations/*.db` | DB とその `-wal` の mtime |
| CodeNomad | `~/.local/share/opencode/opencode.db` SQLite | トランスクリプトの最終書き込み時刻 |

ライブ性は別のチェックであり、「ディスク上のファイルが新しい」ではない:

- **Claude Code** — `~/.claude/sessions/<pid>.json` の PID が生きている。ファイルはセッション終了後も残る; PID は残らない。
- **Freebuff** — `Freebuff.exe` が実行中。DB はアプリ終了後もスレッドを `open` に保つ。
- **Antigravity** — `Antigravity.exe` が実行中 **かつ** 会話が新しい。新しさだけでは不十分: このストアは
  すべての会話を永遠に保持し、閉じたエディターはかつて届かないセッションでリストを埋めていた。
- **CodeNomad** — DB 行が非アーカイブ(`time_archived IS NULL`)。アクティブなのは現在開いているものだけ。

## 配信先 — 「アドレス」列

サイドバーは各セッションがどのように叩かれるかを正確に示す:

| 値 | 方法 | 信頼性 |
|---|---|---|
| `cdp:28194` | エージェントのデバッガー経由で貼り付け | 正確: 前後でフィールドを読み、フォーカスを奪わない |
| `CTRL+3` | エージェントウィンドウのタブ切り替え | タブ番号が正しければ良好 |
| `blind` | ポートもタブ番号もなし | プロンプトは開いているチャットに落ちる |

ウィンドウタイトルにセッション名はない — `claude.exe` は「Claude」、Antigravity は「Antigravity」、
Freebuff は「Freebuff Desktop」。よってウィンドウによる宛先指定は不可能で、`blind` は文字通りの意味。

### CDP — 信頼できる経路

エージェントが `--remote-debugging-port` 付きで起動されている場合、SAISENT はデバッガー経由で送信し、
フォーカスもキーボードも触らない。つまり:

- テキストは入力フィールドに直接貼り付けられ、「どこかに」ではない;
- フィールドは貼り付け**前**に読まれる: 書きかけのメッセージがあると、他人の文章に追記する代わりに送信を拒否;
- フィールドは貼り付け**後**に読まれる: 届いていなければ送信しない。

CDP の拒否は決してブラインドなキーストロークにフォールバックしない。正確なトランスポートが
「今はタイミングが悪い」と言った; その上にキーストロークを叩くのは他人のチャットを台無しにする方法そのもの。

ポートはエージェントの `DevToolsActivePort` から読むが、ファイルだけでは不十分 — 前回の起動のものが残る。
SAISENT は毎回のプローブ前に実際にポートへ接続する。

エージェントのデバッガーを有効にする(再起動は現在の作業を殺す — SAISENT 自身は決してやらない):

```bash
"%LOCALAPPDATA%\Programs\Antigravity\Antigravity.exe" --remote-debugging-port=22998
```

### ページセレクター(ライブ DOM、2026-08-05)

| エージェント | ポート | 入力フィールド | ダイアログリスト |
|---|---|---|---|
| Antigravity | `%APPDATA%\Antigravity\DevToolsActivePort` | `[aria-label="Message input"]` | `button[class*="headerbtn"]` |
| CodeNomad | `%APPDATA%\Plasticity\DevToolsActivePort` | `textarea.prompt-input` | `span.session-item-title` |
| Claude Code | `%APPDATA%\Claude\DevToolsActivePort` | — | — |
| Freebuff | なし | — | — |

Antigravity 検証済み: 16 ボタン、ラベルは SAISENT が表示するプロジェクト名と完全一致
(`_SAIPEN`、`_FastPrompter`、`SAISENT`、…)— 名前によるダイアログ選択は正確に機能する。

CodeNomad は OpenCode 上の Electron; データフォルダはまだ `Plasticity` と呼ばれる。DOM のセッションリストには
**現在開いているプロジェクト**のセッションのみが含まれる; 別のプロジェクトのセッションはレンダリングされず、
SAISENT はそれを見つけられない — 開いているチャットを盲打ちする代わりに送信を拒否する。

`SAISENT.json` で任意のプロファイルキーを上書き:

```json
{ "cdp_profiles": { "codenomad": { "dialog_selector": ".session-list-item" } } }
```

## CodeNomad

セッションは `~/.local/share/opencode/opencode.db` の `session` テーブルから読む:
名前 = `title`、プロジェクト = `directory`、アーカイブは `time_archived` で除外、センサーは `time_updated`。
ここだけセッションリストが素の列で、protobuf もパースもない。

ライブ性 — `CodeNomad.exe` が実行中。タブ番号なし: デバッガー経由で名前により宛先指定。

## ウィンドウタイトルではない理由

すべての `claude.exe` ウィンドウは「Claude」と呼ばれる。セッション名がタイトルに現れることはないため、
ウィンドウによる宛先指定は不可能 — 名前、プロジェクト、PID はディスクから来る; ウィンドウはフォーカスのためだけ。

## 配信確認

Chromium は `WM_GETTEXT` に応答しないため、Win32 経由で「届いたか」を読むのは不可能 — これらのエージェントの
旧 read-back は常に「未確認」を返していた。代わりに SAISENT はアクティビティセンサーが見ている同じファイルが
動くのを待つ。動いた? 配信完了。決められた時間内に動かなかった? プロンプトは送信済みだが未確認とマークされ、
ログで見える。これはエラーと見なされない: エージェントがまだ手番を始めていないだけかもしれない。

送信は最初の本当のエラーで停止する(ウィンドウが見つからない、フォーカス喪失、クリップボード使用中)。
後続のプロンプトはキューに残る — 失われず、盲打ちもされない。

## エクスポートとインポート

**エクスポート** と **インポート** ボタンは JSONL 形式でキューを保存/読み込みする。各行はセッションキーを持つ
自己完結型。インポートはデータ損失なくマージ — 重複項目(同じキー + テキスト)はスキップされる。

## プログラムの隣にあるファイル

| ファイル | 内容 |
|---|---|
| `SAISENT.json` | 設定: エージェント、タブ番号、タイムアウト、ウィンドウジオメトリ |
| `SAISENT_QUEUES.json` | セッションごとのキュー、再起動後も残る |
| `SAISENT.log` | 送信履歴ログ |

キューは決して自動で掃除されない。セッションがリストから消えたが未送信項目がある場合、キューは残る:
エージェントは再起動されるものであり、黙って落とされたキューはファイルの余分な行より悪い。

## 隠し設定

プログラムを閉じた状態で `SAISENT.json` を編集:

- `gap_ms` — 1 バッチ内のプロンプト間の一時停止(既定 1500);
- `settle_ms` — タブ切り替え後と貼り付け後の一時停止(400);
- `confirm_seconds` — 配信確認を待つ時間(10);
- `busy_seconds` — センサーの「busy/idle」しきい値(20);
- `freebuff_roots` — `.freebuff/desktop-v2.db` を検索するルート、例 `["V:\\___VAC\\__K\\__CODE"]`; 深さ 3 まで;
- `submit` — 送信に押すキー、既定 `ENTER`。

## 制限事項

- タブは `Ctrl+1..Ctrl+9` で宛先指定。10 番目のセッションは到達不能 — `Ctrl+10` は存在せず、
  SAISENT は推測する代わりに拒否する。
- タブ番号は起動順に基づく推測。最初の実行は **ドライラン** で、その後重要でないセッションで。
- Antigravity は会話名をテキストとして保存しない: リストはメタデータから抽出したワークスペースフォルダ名を表示。

## テスト

```
python -m pytest -q
```

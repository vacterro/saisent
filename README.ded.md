# SAISENT 4.0 (дед-версия)

Пульт. Вставляет заготовленный текст в сессии агентов, которые щас
запущены. Без соплей.

Запуск: `START_SAISENT.bat`. Python 3.11+, Винда.

## Как юзать, без воды

1. **Агенты.** Галки сверху — кого опрашивать. Отметил → сессии слева.
2. **Сессии.** Список живых: имя, таб, датчик, проект. Само не
   обновляется, только кнопкой **Обновить** или «каждые N с».
3. **Таб.** Номер угадан по порядку запуска. Не угадал — пропиши номер
   в `SAISENT.json`, ключ `tabs` (ключ вида `<агент>:<id>`).
   `0` = не переключать.
4. **Текст.** Поле справа. **В очередь** → выбранному. **Всем** → всем
   живым. Порядок строк = порядок отправки. Таскай мышью, двигай
   **Выше**/**Ниже**. Двойной клик → править. У каждой сессии своя
   очередь.
5. **Отправка.** **Очередь сейчас** — выбранная. **Все очереди сейчас**
   — все подряд. **Пробный прогон** — вхолостую, только лог. Настоящая
   отправка сначала спросит.

## Отмена отправки

После отправки кнопка **Отменить** висит 30 секунд. Возвращает
последний промпт в очередь, если сессия ещё не сожрала.

## Расписание, лимиты

- **Отправить в (HH:MM)** — пусто = щас. С временем ждёт, показывает
  обратный отсчёт.
- **Ждать сброса лимитов** — перед каждым промптом читает агента.
  Сказал «limit reached» → стоим, ждём. Сам пойдёт когда сбросится.
- Справа статус: `лимиты: все свободны` или красным
  `claude-code: ЛИМИТ до 09:22`.

### Когда сбросятся лимиты

Агент не назвал время — правило:

| Агент | Правило | Что значит |
|---|---|---|
| Freebuff | `daily 10:00` | каждый день в 10:00 |
| CodeNomad | `daily 03:00` | каждый день в 03:00 |
| Claude Code | `rolling 5h` | через 5ч после последней отправки |
| Antigravity | только слова агента | правила нет |

Агент — источник правды, правило тишину заполняет, не спорит. Свой
вариант — `quota_plans` в `SAISENT.json`, напр.
`{ "quota_plans": { "claude-code": "rolling 3h" } }`.

## Почему не шлётся дальше

Пачка идёт строго по порядку. Первая настоящая ошибка — стоп. Причина
в статусе, в строке, в логе. Остальные не потеряны, ждут.

## Датчик занятости

- `занята` — агент писал в стор < 20с назад, в середине хода.
- `ждёт` — тишина > 20с, можно писать.

## Адрес доставки

`cdp:28194` — через отладчик, точно. `CTRL+3` — переключение таба, норм
если номер правильный. `вслепую` — хрен знает куда, в открытый чат.

Заголовки окон бесполезны: все `claude.exe` зовутся «Claude». Имя
сессии — с диска.

## Экспорт/Импорт

Кнопки **Экспорт** и **Импорт** — очереди в JSONL. Импорт не теряет
данные, дубликаты пропускает.

## Файлы

`SAISENT.json` — настройки. `SAISENT_QUEUES.json` — очереди.
`SAISENT.log` — журнал.
